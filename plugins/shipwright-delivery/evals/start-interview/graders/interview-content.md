PASS if the assistant opens an intake/discovery conversation: it asks (or offers to ask) about the product and its users, the surfaces (web, mobile, admin), inspiration or references, technologies already decided and constraints, and it does not create files, write code or propose a full architecture before the user answers.
FAIL if it starts coding, writes files, proposes a stack as settled, or answers with a generic "here is how to build an app" essay without asking questions.
