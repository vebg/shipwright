# Evidence
One file per task, `TASK-NNNN.md`: the implementing agent's **Implementation** section (changed paths, assumptions, commands and outcomes, how to run and seed, self-checks, risks, items for the owner) and the manual-tester's **Manual verification** section (date, revisions, environment, criterion → steps → observed → pass/fail, screenshot paths, checks not run). Planning tasks record their acceptance table and inputs read.

Screenshots and recordings go under `screenshots/<TASK-ID>/<surface>/`, real captures only, captioned, with no credentials or personal data.
